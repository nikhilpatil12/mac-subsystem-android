# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Mac Subsystem for Android (MSA), please report it responsibly:

1. **Do not create a public issue** on GitHub.
2. Please send a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept material directly to the maintainers via GitHub Security Advisories or email: `nikhilpatil12@users.noreply.github.com`.
3. You will receive an acknowledgment within 48 hours.
4. Maintainers will work with you to understand and mitigate the issue before public disclosure.
